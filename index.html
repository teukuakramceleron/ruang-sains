About Physics Lab

Physics Lab adalah laboratorium fisika digital dengan Mode Belajar dan Mode Eksperimen. Semua simulasi adalah educational approximation untuk membangun intuisi fisika, bukan pengganti perhitungan atau simulasi ilmiah presisi (mis. CFD profesional).

Dibangun dengan HTML, CSS, dan JavaScript murni — tidak memerlukan server atau database.
